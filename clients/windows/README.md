# CNC-Robot Studio для Windows

Програма для керування роботом і створення програм руху **без написання коду**.
Ви ставите робота в потрібне положення кнопками jog і записуєте точку однією кнопкою.
Програма збирається з таких кроків, а Studio сама перетворює її на G-код для LinuxCNC.

Studio працює з мостом `system/bt-cnc-bridge` на Raspberry Pi: по **Wi-Fi** (рекомендовано) або по Bluetooth LE.
Стек: Python 3 + PyQt5 + qasync (+ bleak для Bluetooth).

## Вимоги

- Windows 10 або 11.
- Python 3.10+ з https://www.python.org/downloads/. Під час встановлення увімкніть «Add python.exe to PATH».
- **Для Wi-Fi:** ноутбук і Raspberry Pi в одній мережі.
- **Для Bluetooth:** адаптер Bluetooth 4.0+. Сполучати пристрої в налаштуваннях Windows не потрібно.

## Запуск

Двічі клацніть `run_client.bat`. Під час першого запуску він створить `.venv` і встановить залежності.

Вручну (з каталогу `clients\windows`):

```
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m bt_cnc_client
```

## Підключення

1. Виберіть канал зв'язку зі списку:
   - **Wi-Fi.** Введіть адресу Pi: `linuxcnc.local` або IP, наприклад `192.168.137.22`. Порт за замовчуванням 8765, інший можна вказати як `IP:порт`.
   - **Bluetooth.** Натисніть **Пошук** і виберіть `CNC-Robot`.
2. Введіть PIN з `bt-cnc-bridge.txt` на boot-розділі Pi і натисніть **Підключити**.
3. Натисніть **Взяти керування**. Керує лише один клієнт. Без керування доступні тільки статус і **E-STOP**.

## Вкладка «Керування»

- **Безпека і живлення.** **E-STOP** доступний завжди. Порядок запуску: **Скинути E-stop** → **Power On** → **Home All**.
- **Стан.** Для кожного joint видно кут і чи виконано Home. Поруч світові координати X Y Z (у дюймах або мм за INI робота) і кути A B C.
- **Jog.**
  - Простір **Joints (J0–J5)**: рух кожного суглоба окремо. Home для цього не потрібен.
  - Простір **Світ (X Y Z A B C)**: рух інструмента у світових координатах. Потрібен Home.
  - Режим **Утримання**: робот рухається, поки кнопку затиснуто. Якщо зв'язок пропав або вікно втратило фокус, рух зупиняється.
  - Режим **Крок**: одне натискання дає один крок заданої величини.
- **Програми на роботі.** Список файлів на Pi, кнопки Відкрити / Видалити, Run / Pause / Resume / Stop / Step і feed override.
- **MDI.** Один рядок G-коду.

## Вкладка «Навчання» (програма без коду)

1. Поставте робота jog'ом у потрібне положення і натисніть одну з кнопок запису:

   | Кнопка | Що записується | Як рухатиметься робот |
   |---|---|---|
   | **● Записати MoveJ** | кути J0–J5 | усі joints одночасно, найкоротшим шляхом для суглобів |
   | **● Записати MoveL** | позиція X Y Z A B C | інструмент по прямій лінії (потрібен Home) |
   | **● Записати MoveP** | позиція X Y Z A B C | швидкий рух G0 (потрібен Home) |

2. Повторіть для наступних точок. Між ними можна додати:
   - **+ Пауза**: очікування в секундах;
   - **+ Вихід**: цифровий вихід `motion.digital-out-NN`, наприклад захват (команди M64/M65);
   - **+ Коментар**.
3. Правка кроків:
   - виберіть рядок у таблиці;
   - праворуч можна змінити назву, координати, швидкість (0 = типова швидкість програми), тривалість паузи або номер виходу;
   - кнопки **▲ ▼**, **Дублювати**, **Видалити**;
   - **Оновити позицію** записує в крок поточне положення робота;
   - **➜ Перейти до точки**: робот їде до вибраної точки, щоб перевірити її.
4. **Переглянути G-код** показує, що саме буде виконано.
5. **▶ Запустити програму** завантажує програму на Pi (у `ProjectLinuxCNC`), відкриває її і запускає. Потрібні Power On і Home All.
6. **Зберегти** записує програму на ПК у файл `*.robot.json`. **Відкрити** дає змогу продовжити роботу з нею пізніше.

### Як Studio будує G-код

- **Світові рухи** — `G53 G1` / `G53 G0` у кінематиці genserkins (`M428`).
  `G53` означає машинні координати, тож стартові зміщення G54 з `robot.ini` на точки не впливають.
- **Рухи по joints** — identity-кінематика: `M129` (ліміти осей = ліміти joints) і `M429`, тоді X…C = J0…J5.
  Після цього `M128` + `M428` повертають світову кінематику.
- **Швидкість MoveJ** — `F` у °/хв для вектора J0–J2. Вона приблизна, бо LinuxCNC рахує швидкість для перших трьох осей.
- Програма завжди закінчується у світовій кінематиці і командою `M2`.

## Структура

| Файл | Призначення |
|---|---|
| `bt_cnc_client/protocol_client.py` | протокол без Qt: команди, відповіді, `JogHold` (jogc/jogwc + ping) |
| `bt_cnc_client/robot_program.py` | модель програми навчання, JSON, генерація G-коду, без Qt |
| `bt_cnc_client/tcp_transport.py` | Wi-Fi (TCP) |
| `bt_cnc_client/ble_transport.py` | Bluetooth LE (bleak) |
| `bt_cnc_client/main_window.py` | головне вікно, вкладка «Керування» |
| `bt_cnc_client/teach_panel.py` | вкладка «Навчання» |
| `bt_cnc_client/ui_constants.py` | тексти, кольори, діапазони |
| `bt_cnc_client/tests/` | pytest, зокрема наскрізний тест Wi-Fi зі справжнім мостом |

## Тести

```
python -m pip install -r clients/windows/requirements-dev.txt
python -m pytest clients/windows/bt_cnc_client/tests -q
```

На Windows тест `test_wifi_end_to_end.py` пропускається, бо йому потрібен PyGObject (GLib) мосту. Повністю він проходить на Linux.

## Відомі обмеження

- **Немає зворотного зв'язку.** У поточній конфігурації записується **задана** позиція, а не виміряна, бо енкодерів немає. Пропущені кроки мотора програма не побачить.
- **Хоумінг симульований** (`basic_sim`), тож нуль — це положення робота в момент Home.
- **Відповіді по Bluetooth отримують усі підключені клієнти.** По Wi-Fi відповіді адресні.

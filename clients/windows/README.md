# Клієнт CNC-Robot для Windows

Настільна програма для керування роботом через Bluetooth LE. Вона працює з мостом
`system/bt-cnc-bridge`, який запущений на Raspberry Pi. Стек: Python 3 + [bleak](https://github.com/hbldh/bleak) + PyQt5 + qasync.

## Вимоги

- Windows 10 (версія 1709 або новіша) чи Windows 11 з Bluetooth 4.0+ (вбудованим або USB-адаптером).
- Python 3.10+ з https://www.python.org/downloads/. Під час встановлення увімкніть «Add python.exe to PATH».
- Bluetooth у Windows має бути **увімкнений**. Створювати пару з Pi в налаштуваннях **не потрібно**: клієнт підключається напряму.

## Запуск

Найпростіше — двічі клацнути `run_client.bat`. Під час першого запуску він створить
`.venv` і встановить залежності.

Вручну (PowerShell або cmd з каталогу `clients\windows`):

```
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m bt_cnc_client
```

## Робота

1. **Підключення.**
   1. Натисніть **Пошук**. Знайдені `CNC-Robot` з'являться у списку, найсильніший сигнал першим.
   2. Введіть PIN з файлу `bt-cnc-bridge.txt` на boot-розділі Pi.
   3. Натисніть **Підключити**.
2. **Керування.** Натисніть **Взяти керування**: керувати може лише один клієнт. Без керування доступні статус і **E-STOP**.
3. **Підготовка робота.** Натисніть **Скинути E-stop**, потім **Power On**, потім **Home All**.
4. **Jog.**
   - **Утримання (jogc):** робот рухається, поки кнопку `+`/`−` затиснуто. Програма щоп'ять разів на секунду надсилає `ping`. Якщо зв'язок пропадає або вікно втрачає фокус, рух зупиняється.
   - **Крок (jog):** одне натискання переміщує joint на заданий крок.
   - Швидкість міст обмежує до `MAX_JOG_VEL` і лімітів з INI. Фактична швидкість видно в журналі.
5. **Програма.**
   1. Натисніть **Оновити**, щоб отримати список файлів з `PROJECTS_DIR`.
   2. Відкрийте файл подвійним кліком або кнопкою **Відкрити**.
   3. Запустіть **Run**. Під час виконання доступні **Pause**, **Resume**, **Stop** і **Step**.
   4. Повзунок Feed змінює feed override.
6. **MDI.** Поле приймає один рядок G-коду. Потрібні стан On і виконаний Home.

Якщо з'єднання обірвалося, міст сам зупиняє jog і ставить програму на паузу (або abort, залежно від `ON_DISCONNECT`).

## Структура

| Файл | Призначення |
|---|---|
| `bt_cnc_client/protocol_client.py` | протокол v1 **без Qt і bleak**: розбір рядків, черга відповідей, `JogHold` (jogc + ping). Основа для Android-клієнта |
| `bt_cnc_client/ble_transport.py` | bleak: пошук, підключення, notify, запис пакетами під MTU |
| `bt_cnc_client/main_window.py` | вікно PyQt5 |
| `bt_cnc_client/ui_constants.py` | тексти, кольори, діапазони |
| `bt_cnc_client/__main__.py` | точка входу (qasync) |
| `bt_cnc_client/tests/` | pytest: логіка клієнта і наскрізний тест зі справжнім `Bridge` мосту |

Протокол описано в `system/bt-cnc-bridge/README.md`.

## Тести

Тести запускаються з кореня репозиторію, Windows або Linux:

```
python -m pip install -r clients/windows/requirements-dev.txt
python -m pytest clients/windows/bt_cnc_client/tests -q
```

## Відомі обмеження

- **Один клієнт за раз.** BLE notify отримують усі підключені клієнти, а відповіді зіставляються за порядком. Другий підключений клієнт може «перехопити» чужу відповідь.
- **Якщо Windows не знаходить пристрій:**
  - перевірте, що сервіс на Pi працює: `systemctl status bt-cnc-bridge`;
  - перевірте, що Pi не підключений до іншого клієнта;
  - вимкніть і знову ввімкніть Bluetooth у Windows.

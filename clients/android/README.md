# CNC-Robot для Android (мобільний веб-додаток)

Пульт робота для телефона. Сторінку роздає сам Raspberry Pi, тож встановлювати
нічого не треба: досить відкрити адресу в Chrome і додати її на головний екран.
Тоді додаток запускається з іконки на весь екран, як звичайний.

Можливості — ті самі, що й у Windows-програмі CNC-Robot Studio (`clients/windows`):

- **Пульт:**
  - E-STOP завжди внизу екрана;
  - скидання E-stop, Power, Home All;
  - jog по joints (J0–J5) або у світових координатах (X Y Z A B C);
  - режим **утримання** (робот їде, поки палець на кнопці) або **крок**.
- **Навчання:**
  - запис поточного положення як MoveJ, MoveL або MoveP;
  - паузи, виходи, коментарі;
  - перестановка й видалення кроків, «Оновити позицію»;
  - «Перейти до точки» і запуск програми;
  - збереження на телефоні, експорт та імпорт `*.robot.json`, сумісний зі Studio.
- **Програми:** список файлів на роботі, відкриття, Run / Pause / Resume / Stop, feed override, MDI.

## Як це працює

```
Телефон (Chrome) --WebSocket--> websockify :8780 --TCP--> bt-cnc-bridge :8765 --NML--> LinuxCNC
```

- **`websockify`** уже стоїть на Pi, бо його використовує noVNC. Він роздає файли з цього каталогу і перекидає WebSocket на міст.
- **Протокол, PIN і безпека** ті самі, що для Bluetooth і Windows:
  - керує один власник;
  - jog утриманням підтримується `ping` кожні 200 мс, і без них міст зупиняє рух;
  - якщо зв'язок обірвався, міст зупиняє jog і ставить програму на паузу.
- **Якщо додаток згорнули або вимкнули екран** під час утримання, jog зупиняється одразу.

## Встановлення на Pi

Потрібен оновлений міст `system/bt-cnc-bridge` з доступом по Wi-Fi (TCP 8765).

```
sudo bash ~/linuxcnc/configs/LinuxCNC_PA/clients/android/install.sh
```

Або офлайн, з картки, вставленої в ПК:

```
sudo bash install.sh --root /media/$USER/rootfs
```

Інсталятор встановлює сервіс `cnc-web`, який працює від `cnc` на порту 8780. Додаток роздається прямо з
репозиторію, тому `git pull` одразу оновлює його. Сервіс на інший порт ставить `--port N`.

## На телефоні

1. Підключіть телефон до тієї ж Wi-Fi мережі, що й Pi.
2. Відкрийте в Chrome `http://<IP Pi>:8780/`, наприклад `http://192.168.137.22:8780/`. Адреса Pi в полі «Зв'язок» підставиться сама.
3. Введіть PIN з `bt-cnc-bridge.txt` і натисніть **Підключити**, потім **Взяти керування**.
4. Додайте додаток на головний екран: меню Chrome **⋮** → **Додати на головний екран**.

## Розробка і тести

| Файл | Призначення |
|---|---|
| `index.html`, `style.css` | інтерфейс (mobile-first, світла й темна тема) |
| `js/protocol.js` | протокол v1: черга відповідей, `JogHold` (порт `protocol_client.py`) |
| `js/program.js` | програма навчання і G-код (порт `robot_program.py`) |
| `js/app.js` | WebSocket і прив'язка інтерфейсу |
| `cnc-web.service`, `install.sh` | сервіс websockify на Pi |
| `tests/` | тести |

```
node --test clients/android/tests/                 # протокол і паритет G-коду з Python
python3 clients/android/tests/run_e2e.py [каталог]  # міст + websockify + Chrome, скриншоти
```

- **Тест паритету** перевіряє, що JS-генератор дає **той самий** G-код і ім'я файлу, що й Studio.
- **`run_e2e.py`** запускає міст із моком `linuxcnc` і справжній `websockify`. Потім headless Chrome з емуляцією телефона натискає кнопки в додатку: підключення, jog утриманням, запис точок, запуск.
  Потрібні Python з PyGObject і `websockify`, Node 20+ і Google Chrome.

## Обмеження

- Трафік по Wi-Fi не шифрується (звичайний `http`/`ws`). Використовуйте лише в довіреній локальній мережі.
- Bluetooth з браузера не використовується, бо Web Bluetooth вимагає HTTPS. З телефона по Bluetooth можна працювати через Serial Bluetooth Terminal (див. `system/bt-cnc-bridge/README.md`).
- Позиції записуються як задані, а не виміряні (енкодерів немає). Хоумінг поки симульований.
